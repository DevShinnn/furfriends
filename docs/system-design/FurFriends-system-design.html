System design

FurFriends

System architecture, database (ERD) and flows

FurFriends is an installable web app where cat and dog owners in the Philippines keep their pets' health records, get care reminders, read first-aid guides, find nearby vet clinics, and ask the FurFriends AI, in English or Tagalog.

What owners can doKeep profiles, medical history, vaccinations and documents for each pet; plan feeding and care with reminders; read first-aid and breed guides; find nearby vet clinics with hours and directions; ask the assistant.
How it is builtA React web app that works offline, a Supabase backend with private per-owner data, push reminders, and the team's own trained AI, running in a free Vercel function.
What this document shows1. Architecture 2. Technology 3. ERD and data dictionary 4. Flows: sign-in and sync, the assistant, reminders, research data, deployment 5. Security and limits.

Live at furfriends-black.vercel.app. The database section matches supabase/migrations: 14 tables, 15 relationships (checked against the live project on 2026-10-24; ai_usage added 2026-10-28, clinic_search_cache 2026-10-29). Document date: 2026-10-29.

1. System architecture

Three places do the work: the owner's device (app, offline cache and the search), Vercel (serves the app and runs the AI that writes answers) and Supabase (accounts, data, files, sync, reminders and the AI's usage limit).

Each layer and the reason it was chosen.

4. Data dictionary

14 tables in the public schema, plus Supabase's own auth.users. Every table has Row Level Security on.

TableOne row isKeyRules
profilesan owner's name, phone, city, address and reminder settingid (the user's id)One per user, created at sign-up.
petsa cat or a dogidSpecies is Cat or Dog; age months 0 to 11; weight above 0.
medical_recordsa checkup, illness, injury, surgery, medication or allergyidBelongs to a pet.
vaccinationsa vaccine given, with its next due dateidNext due date is after the date given.
documentsan uploaded photo or PDFidThe file is in private storage; the row keeps its path.
feeding_schedulesa meal time with food and amountidDays 0 to 6, empty means every day.
feeding_loga meal ticked as fed on one dayfeeding_id + fed_onOnly the last 14 days are loaded.
care_tasksgrooming, deworming, vaccination or a vet appointmentidRepeat in days (0 = once); vet appointments are rows here, not a separate table.
assistant_feedbacka thumbs up or down on one assistant answeridKeeps the question, answer and model version; rating is 1 or -1.
push_subscriptionsa phone or browser that allowed notificationsidEndpoint is unique; keeps the device's time zone.
push_loga reminder already pusheduser_id + keyStops the same reminder going out twice.
usability_responsesone tester's surveyidExactly 10 answers from 1 to 5; SUS score computed.
clinic_search_cacheone saved TomTom clinic search for a ~1 km area, or a typed address's locationkeyKept a week. Only the find-clinics function reads or writes it (no user policies); addresses are stored as a hash.
ai_usagethe CPU time one AI answer usedidNo question text. Users can add rows but not read them; the AI stops at 3 CPU-hours per 30 days.

Not in the database on purpose: the first-aid guides, breed guide and the assistant's answers are built into the app, so they work offline. There is no clinics table: nearby clinics come live from TomTom, and clinic_search_cache only keeps each search for a week.

6. Flow: asking the assistant

Rules run first. Then the device finds the 2 closest checked passages, and FurFriends' own model on Vercel writes the answer from them. If it can't, the closest checked answer shows, only when it is close enough.

7. Flow: reminder notifications

A schedule in the database wakes an edge function every 5 minutes. Reminders arrive even when the app is closed.

8. Flow: research data and improving the assistant

Survey answers and ratings are collected from real testers only, then used to measure usability and to fix wrong answers.

9. Flow: deployment

Code and data go through local checks, then GitHub, then Vercel. Database changes are SQL migrations applied to Supabase.

10. Security, privacy and limits

AreaHow it is handled
Each owner sees only their own dataRow Level Security on all 14 tables; a pet's rows are visible only when its owner is the logged-in user. Visitors who are not logged in see nothing.
Files are privatePhotos and documents sit under a folder named with the owner's user id, locked by a storage policy, and are opened with links that expire after a week.
Secrets stay on the serverThe app holds only the public Supabase key. The service-role key and push private key live in the edge function's secrets. A secret scan runs before every push and passed on the whole history.
Locations aren't keptThe phone's location is used for one search and never saved. Searches are saved per ~1 km area, and a typed address only as a hash. The TomTom key is an edge-function secret, and only logged-in owners can search.
Questions go only to FurFriends' own AIOnly logged-in owners can use it. The question and 2 checked passages go to the team's function on Vercel, not to a paid AI service, and are not stored. A question is shared with the team only when the owner rates the answer.
The free plan can't be overrunEach answer's CPU time is logged in Supabase. Above 3 of the free 4 CPU-hours per 30 days, the AI stops and the checked answer shows instead, so the app is never paused.
Shared demo accounts are protectedThe demo and sample logins have public passwords, so the database refuses changes to their password or email, and refuses their survey answers and ratings.
The assistant is cautiousIt writes only from 2 checked passages, never gives medicine doses, puts the first-aid guide first in an emergency, shows its sources, and says when the passages don't answer the question.
Limits to state honestly
  • The AI is a small model (0.5 billion parameters). It writes from the 2 closest checked passages but can still pick the wrong ones or word an answer wrongly, and the screen says so. It is not a vet.
  • There is no vet adviser. Answers are written from public sources (VCA, Merck, Cornell, ASPCA, WSAVA, Philippine laws) and checked against them by the team, which is a limitation to state.
  • Tagalog and Taglish work through a word list that turns common words into English before the search. Unusual wording can still be missed.
  • The search model (about 30 MB) downloads once, on the first question. Writing answers needs internet; offline, the closest checked answer shows instead.
  • The AI shares Vercel's free plan: about 25 to 50 CPU-seconds per answer, so roughly 200 to 400 answers per 30 days before it falls back to checked answers.
  • Clinic listings and hours come from TomTom and can be wrong or out of date; about half of Batangas clinics have no hours listed, and small towns have few listings. The app says to call before going.
  • Survey and grading results shown anywhere as SIMULATED are practice data only, not research results.
